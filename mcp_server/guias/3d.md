# Sólidos 3D: primitivas, extrusión, booleanas y vista isométrica

Todo en metros, en el espacio activo (`space`): si el activo es un layout,
pasá a Model con `set_current_layout("Model")` antes. Lo que no agregues
con `Add()` no queda en el dibujo y hay que hacerle `Dispose()`.

## Primitivas: nacen CENTRADAS en el origen

`CreateBox`, `CreateFrustum` y `CreateSphere` dibujan centrado en (0,0,0):
la caja va de -L/2 a +L/2 en cada eje. Se ubican después con `TransformBy`.

```csharp
// Caja 4 x 3 x 2.5 con la esquina inferior en (10, 0, 0)
var caja = new Solid3d();
caja.SetDatabaseDefaults();
caja.CreateBox(4.0, 3.0, 2.5);              // largo X, ancho Y, alto Z
caja.TransformBy(Matrix3d.Displacement(new Vector3d(10 + 4.0 / 2, 3.0 / 2, 2.5 / 2)));
caja.Layer = "3D-MUROS";                    // la capa tiene que existir
string hCaja = Add(caja);                   // Add devuelve el handle

// Cilindro r=0.15, h=3 (columna): frustum con los tres radios iguales.
// Cono: topXRadius = 0. El eje es Z y también nace centrado en altura.
var col = new Solid3d();
col.SetDatabaseDefaults();
col.CreateFrustum(3.0, 0.15, 0.15, 0.15);   // height, xRadius, yRadius, topXRadius
col.TransformBy(Matrix3d.Displacement(new Vector3d(2, 2, 1.5)));
Add(col);

var esf = new Solid3d();
esf.SetDatabaseDefaults();
esf.CreateSphere(0.5);
```

## Extruir un contorno: Polyline cerrada → Region → Solid3d

```csharp
var pl = new Polyline();
pl.AddVertexAt(0, new Point2d(0, 0), 0, 0, 0);
pl.AddVertexAt(1, new Point2d(6, 0), 0, 0, 0);
pl.AddVertexAt(2, new Point2d(6, 0.15), 0, 0, 0);
pl.AddVertexAt(3, new Point2d(0, 0.15), 0, 0, 0);
pl.Closed = true;

var curvas = new DBObjectCollection();
curvas.Add(pl);
DBObjectCollection regiones = Region.CreateFromCurves(curvas);
var reg = (Region)regiones[0];

var muro = new Solid3d();
muro.SetDatabaseDefaults();
muro.Extrude(reg, 2.50, 0.0);               // región, altura, ángulo de ahusado
string h = Add(muro);

foreach (DBObject o in regiones) o.Dispose(); // nada de esto entró al dibujo
pl.Dispose();
return h;
```

Para extruir una polilínea YA dibujada: `tr.GetObject(H("2A3"), OpenMode.ForRead)`
y pasala en la colección; no la toques ni la dispongas (es de la transacción).
`CreateFromCurves` necesita curvas cerradas y coplanares: si no, tira
`eInvalidInput` o devuelve la colección vacía — chequeá `regiones.Count`.

## Booleanas: restar vanos, unir piezas

```csharp
// 'muro' ya agregado con Add() (queda abierto para escritura en tr).
var vano = new Solid3d();
vano.SetDatabaseDefaults();
vano.CreateBox(0.90, 0.40, 2.10);           // puerta: ancho x (más que el muro) x alto
vano.TransformBy(Matrix3d.Displacement(new Vector3d(2.0, 0.075, 2.10 / 2)));
muro.BooleanOperation(BooleanOperationType.BoolSubtract, vano);
vano.Dispose();                             // queda vacío después de la operación
```

`BoolUnite` une, `BoolIntersect` deja lo común. El segundo sólido se consume:
si estaba en el dibujo, borralo (`Erase()`); si no, `Dispose()`.
Sobre un sólido existente: `(Solid3d)tr.GetObject(H(".."), OpenMode.ForWrite)`.
Hacé el vano un poco más profundo que el muro: una cara coincidente puede dejar
una lámina sin restar.

## Mover, rotar, medir

```csharp
s.TransformBy(Matrix3d.Displacement(new Vector3d(dx, dy, dz)));
s.TransformBy(Matrix3d.Rotation(Math.PI / 2, Vector3d.ZAxis, new Point3d(0, 0, 0)));

Solid3dMassProperties mp = s.MassProperties;   // volumen real para cuantificar
Print("vol m3 = " + mp.Volume.ToString("0.000"));
Print("centroide = " + mp.Centroid);
```

Firma dudosa: `MassProperties` es propiedad (no método) en 2022 según la
documentación que conocemos — confirmalo con `describe_api("Solid3d", "Mass")`.

## Vista isométrica SO y estilo visual

```csharp
ViewTableRecord vista = ed.GetCurrentView();
vista.ViewDirection = new Vector3d(-1, -1, 1);   // SO. SE (1,-1,1), NE (1,1,1), NO (-1,1,1)
var estilos = (DBDictionary)tr.GetObject(db.VisualStyleDictionaryId, OpenMode.ForRead);
if (estilos.Contains("Realistic"))
    vista.VisualStyleId = estilos.GetAt("Realistic");  // nombres internos en inglés
ed.SetCurrentView(vista);
vista.Dispose();
return null;
```

Después, la tool `zoom_extents` encuadra y `capture_viewport` saca la foto.
Nombres internos de estilos: "2dWireframe", "Wireframe", "Hidden",
"Realistic", "Conceptual", "Shaded" (pueden variar con la plantilla:
recorré el diccionario si no aparece). `VisualStyleId` sobre la vista es la
parte menos segura de esta guía: verificalo con
`describe_api("AbstractViewTableRecord", "VisualStyle")`. Si no aplica, el
camino alternativo es el `ViewportTableRecord` de `ed.ActiveViewportId`
abierto ForWrite + `ed.UpdateTiledViewportsFromDatabase()`.
